Sync between computers

Optional GitHub sync for the notes library. Without this, notes stay on this device.

First time? Create the repo, then create a token and paste it below.

The token is stored in Chrome sync storage so your signed-in Chromes can reuse it. Proofly sends it only to GitHub for the repository you choose.

Manual setup
  1. Create a private GitHub repository, for example proofly-notes.
  2. Create a fine-grained personal access token for only that repository.
  3. Give it Contents: read/write, generate it, then paste it above.
